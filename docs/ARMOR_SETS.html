Armor Set Bonuses

Every item set in the game, from the stock end-of-retail spell table (client_portal.dat) read with ACE's own reader. Set id = item property 265. Rules (ACE WorldObject_Set.GetSpellSet): the bonus depends on how many pieces of the set you wear (Aetheria and cloaks count item levels instead), capped at the top tier; a count between tiers uses the tier below. Set bonuses apply even if the pieces' own magic cannot activate (ACE: "set spells are not affected by mana"). Set spells are their own spell families, so they stack with buffs and cantrips.
